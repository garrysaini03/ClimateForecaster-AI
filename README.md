# ClimateForecaster-AI
🚀 1. Project Title / Headline Global Temperature Prediction App with Random Forest Modeling

📌 2. Short Description / Purpose This project is an interactive machine learning application designed to predict global temperatures based on historical climate data. By analyzing land temperature records, the model identifies climate trends and provides real-time forecasts to help users understand global warming patterns through a user-friendly interface.

🧠 3. Tech Stack * Programming: Python (Pandas, NumPy)

Machine Learning: Scikit-learn (Random Forest Regressor)

Deployment/UI: Streamlit

Data Processing: Python-based ETL and feature engineering

📂 4. Data Source * Dataset: Global historical weather records.

Contents: Historical land average, maximum, and minimum temperature data.

🌟 5. Features / Highlights 📊 Key Metrics & Performance * High Accuracy: Achieved a 92% prediction accuracy for climate trends.

Low Error: Optimized model to reach a Test MSE of approximately 0.031.

📈 Advanced Modeling * Ensemble Learning: Utilized 100 decision trees in a Random Forest model for robust predictions.

Cleaned Data Pipeline: Automated removal of uncertainty metrics and null values to ensure data integrity.

Feature Engineering: Extracted time-based features from datetime records to improve seasonal forecasting.

🌍 Interactive Predictions * Real-Time Forecasting: Deployed a web app where users can input land temperatures to receive instant predictions.

Dynamic Inputs: User-friendly sliders and number inputs for Average, Maximum, and Minimum land temperatures.

🎯 User-Friendly Interface * Streamlit Deployment: Provides a professional dashboard interface that abstracts complex code for non-technical users.

Efficient Processing: Integrated multi-core CPU usage (n_jobs=-1) for faster model training and responsiveness.

This project demonstrates my proficiency in building end-to-end machine learning solutions, from data cleaning and complex regression modeling to deploying interactive web applications for business and environmental intelligence.
